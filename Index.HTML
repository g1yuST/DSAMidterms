Setting up Git

1. Go to https://git-scm.com/

2. Go to Downloads and choose your OS. Click the Standalone Installer and install it.

3. Go to your file manager, right-click to check if Git is installed properly. Create a file (for example, HelloWorld.html).

4. Open Git Bash and type these commands:

git config --global user.name "Your Name"
git config --global user.email "you@youraddress.com"
git config --global push.default matching
git config --global alias.co checkout
git init

All information must be accurate with your GitHub account.

5. Then type these commands:

git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/g1yuST/DSAMidterms
git push -u origin main

Make sure you added the file README.md before running this.

Refresh GitHub to check if the files are uploaded.

Life Hack

Open Git Bash and type:

git clone https://github.com/g1yuST/DSAMidterms.git

You can now access your files anywhere.

Setting up GitHub

1. Go to https://github.com/

2. Sign up or sign in using your school email.

3. Create a repository named DSAMidterms. Set it to Public.

4. You will see “create a new repository on the command line.”

5. Since you already have the files, you can view or compile them in your repository.

6. Check that all files are synced.

Setting up Visual Studio Code

1. Go to https://code.visualstudio.com/

2. Choose your OS and install it.

3. Sync everything with your GitHub account.

4. Create a file for your work.

5. Press Ctrl + A on the name bar above and replace it with cmd to access Command Prompt easily.

6. Type code . and VS Code will open. Check if it’s synced with GitHub.

7. Go to Terminal → add Command Prompt. Turn on Auto Save. Add extensions for Conventional Commits and Source Control.

8. Create a simple HTML file “HelloWorld” and test it.

9. Use Source Control to check changes, stage them, and commit. Then push to GitHub.
