Setting up Git, GitHub, and Visual Studio Code

Setting up Git

1. Go to the site: https://git-scm.com/

2. Go to Downloads then choose what OS you have. Click the Standalone Installer, choose what you have, and install it.

3. Go to your file manager and right-click to check if Git is installed properly. Create a file (for example, HelloWorld.html).

4. After creating the file, open Git Bash and type the following commands:

git config --global user.name "Your Name"
git config --global user.email "you@youraddress.com"
git config --global push.default matching
git config --global alias.co checkout
git init

All information must match your GitHub account.

5. After that, type these commands:

git init
git add README.md
git commit -m "first commit"
git branch -M main
git remote add origin https://github.com/g1yuST/DSAMidterms
git push -u origin main

Make sure you added the file README.md for this to work properly.

6. Refresh GitHub to check if the files are uploaded.

Life Hack:

Open Git Bash and type this command:

$ git clone https://github.com/g1yuST/DSAMidterms.git

You can now access your files anywhere and anytime.

Setting up GitHub

1. Go to the site: https://github.com/

2. Sign up or Sign in using your school email.

3. Create a new repository and name it DSAMidterms. Set it to Public.

4. You will see the section "create a new repository on the command line."

5. Since you already have the files, you can view, edit, and compile them in your repository.

6. Double-check that all the files are synced properly.

Setting up Visual Studio Code

1. Go to the site: https://code.visualstudio.com/

2. Choose your operating system and install Visual Studio Code.

3. Sync everything that you set up in GitHub.

4. Create a file where you will compile your work.

5. Press Ctrl + A on the name bar above and replace it with cmd to access the command prompt easily.

6. Type code . and VS Code will open. Double-check that it’s synced with GitHub.

7. Go to the Terminal and add Command Prompt. Enable Auto Save. Add Extensions for Conventional Commits and Source Control.

8. Create a simple HTML file named HelloWorld.html and test it.

9. Use Source Control to view your changes, stage them, and commit. Then push them to GitHub. Click the circle icon to commit using Conventional Commit. Sync and refresh GitHub to confirm the changes.

Try Another Example:

1. Make another HTML file to see the differences in Source Control.

2. Duplicate the file if needed and try adding notations or emojis.

3. Save it and check GitHub again.

4. Try adding a new line in the README.md file and check if it appears in your repository.
